# 任务列表（Task Lists）

> 本文档覆盖 VividMark 的 GFM 任务列表语法与交互行为，可用于测试四种视图模式的渲染与点击切换，兼作手动验收 fixture。

**快速体验**

- **预览模式**：点击复选框切换勾选状态，自动写回源码（`- [ ]` ⇄ `- [x]`）
- **WYSIWYG 模式**：点击复选框同样切换，保存后源码同步更新
- **插入入口**：格式菜单 / 右键菜单「格式 ▸ 任务列表」/ 快捷键 `Cmd/Ctrl + Alt + X`；Source 模式直接输入 `- [ ] ` 后回车可智能续行

## 语法速览

| 状态   | 语法         | 说明                          |
| ------ | ------------ | ----------------------------- |
| 未勾选 | `- [ ] 任务` | 方括号内一个空格              |
| 已勾选 | `- [x] 任务` | 小写 `x`（大写 `X` 同样识别） |

## 1. 基本用法

- [ ] 未勾选的任务
- [x] 已勾选的任务
- [x] 大写 X 同样识别为已勾选

## 2. 连续多任务

- [ ] 设计评审
- [ ] 编写实现
- [x] 单元测试
- [ ] 更新文档
- [ ] 发布版本

## 3. 嵌套任务列表

- [ ] 第一阶段：基础框架
  - [x] 项目脚手架
  - [x] 构建链路
  - [ ] 代码规范
- [x] 第二阶段：核心编辑器
  - [x] 编辑内核
  - [x] 实时预览

## 4. 任务项内的行内语法

- [ ] 修复 **加粗** 强调的回归问题
- [x] 重构 `parser.ts` 的行内解析
- [ ] 参考 [GFM 规范](https://github.github.com/gfm/#task-list-items-extension-) 对齐行为
- [x] 移除 ~~废弃的全文快照撤销方案~~（已由编辑器 history 取代）

## 5. 与普通列表混排

- 普通无序列表项（无复选框、不可点击）
- [ ] 同一列表中的任务项
- 又一个普通列表项
- [x] 已完成的任务项

`*` 标记同样识别：

- [ ] 星号标记的未勾选任务
- [x] 星号标记的已勾选任务

## 6. 边界写法（不识别为任务列表，原样保留）

- [ ]缺少空格不识别（`]` 后必须跟空白）
- [] 空方括号不识别
- [y] 其他字符不识别

有序列表中的 `[ ]` 标记在预览侧不识别（GFM 规范支持，预览实现仅覆盖 `-` / `*` 无序标记）：
