Features

🌐

Docs Site Export

Export an opened docs folder as a ready-to-deploy static site — mkdocs-style navigation, rewritten cross-page links, and light/dark toggle, with zero external dependencies.

📝

Four View Modes

WYSIWYG, Source, Preview, and Split view with sync scrolling for flexible editing.

⚡

Real-time Preview

See your formatted Markdown instantly as you type.

🎨

Syntax Highlighting

Beautiful code highlighting powered by highlight.js.

📦

File Operations

Open, save, and manage Markdown files with native system dialogs.

🔄

Auto-save

Automatic saving after 2 seconds of inactivity.

↩️

Undo/Redo

Full history support with keyboard shortcuts.

📊

Extended Markdown

Tables, admonitions, PlantUML diagrams, and KaTeX math formulas support.

🌙

Dark Mode

Light, dark, or auto (follows system) themes for comfortable writing.

🗂️

File Management

File tree with search and create/rename/delete, plus a collapsible outline that follows your cursor.

🪟

Multi-window

Typora-style SDI: one window per document, with smart routing that focuses an already-open file.
