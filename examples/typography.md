# 排版增强（高亮 / 上标 / 下标 / Emoji）

四类行内语法：`==高亮==`、`^上标^`、`~下标~`、`:emoji短码:`。
预览 / 分屏 / PDF / 站点导出全链路渲染；WYSIWYG 中高亮、上下标为真实格式
（可编辑、保存后源码不变），emoji 保持字面短码文本（预览渲染为图形字符）。

## 高亮（==mark==）

==这是一段高亮文字==，用于强调关键结论。

高亮内可以嵌套其他行内格式：==含 **加粗**、*斜体* 与 `代码`==。

字内配对同样有效：a==b==c（字母相邻不需要空格）。

## 上标（^sup^）

经典公式：E = mc^2^；序数写法：1^st^、2^nd^、3^rd^。

字内配对：x^2^y。

## 下标（~sub~）

化学式：H~2~O、CO~2~；数学下标：a~n~ = a~n-1~ + a~n-2~。

字内配对：H~2~O 无需空格。

注意与删除线的区分：单 `~` 是下标（~sub~），双 `~~` 是删除线（~~del~~）。

## Emoji 短码

常用：:smile: :+1: :heart: :rocket: :tada: :warning: :bulb: :memo:

行首、行中均可：今天心情不错 :sunny:，适合写文档 :pencil2:。

## 混排与组合

==高亮中的 ^上标^ 与 ~下标~==，以及 **加粗里的 ==高亮== 和 ^上标^**。

| 语法     | 源码          | 渲染          |
| -------- | ------------- | ------------- |
| 高亮     | `==文字==`    | ==文字==      |
| 上标     | `^2^`         | ^2^           |
| 下标     | `~2~`         | ~2~           |
| 删除线   | `~~文字~~`    | ~~文字~~      |
| Emoji    | `:smile:`     | :smile:       |

## 边界与降级形态

以下写法**不会**解析，保持字面文本（双端口径一致）：

- 分隔符内侧紧邻空白：`== x ==`、`~ x~`、`^x ^`
- 单等号：`=x=`
- 代码区内：`` `==x==` ``、`` `:smile:` ``（行内代码保持字面）

以下是普通文本中的分隔字符，不会被误认为语法：

- 等式 a = b 与连续等号 a == b（纯文本，非高亮）
- 异或运算 a ^ b（纯文本，非上标）
- 波浪号约等于 ~100（行首单个 `~` 后随数字，非空白紧邻规则见上）

超长分隔符（`===x===`、`^^x^^`）属病态写法，双端口径不同：预览只解析
内层配对（如 `=` + ==x== + `=`），WYSIWYG 整体保持字面——请避免使用。

## WYSIWYG 编辑说明

- 输入 `==文字==`、`^上标^`、`~下标~` 的闭合分隔符时自动转为对应格式
  （与 `~~删除线~~`、数学公式同款的输入规则体验）。
- 高亮 / 上标 / 下标以真实格式显示，光标进入后可继续编辑；保存 / 切换模式
  后源码保持 `==` / `^` / `~` 原样。
- emoji 短码在 WYSIWYG 中保持 `:smile:` 字面文本，切到预览即渲染为 😄。
