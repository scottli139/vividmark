# GitHub Alerts（`> [!NOTE]`）

GitHub 原生警示框语法（2023 起），与 Obsidian callouts 同源。引用块首行写
`[!TYPE]` 独占一行即渲染为提示框；VividMark 双端（WYSIWYG / 预览 / 分屏 /
PDF / 站点导出）均支持，WYSIWYG 中标记行保持可见可编辑（改 `[!TIP]` 即换色）。

五种类型与 `:::` / `!!!` 提示框共用同一套配色。

## 五种类型

> [!NOTE]
> 普通提示：用户扫读时也应该知道的信息。

> [!TIP]
> 实用建议：把事情做得更好或更省力的方法。

> [!IMPORTANT]
> 关键信息：达成目标必须知道的内容。

> [!WARNING]
> 紧急提醒：需要立即注意、否则可能出问题。

> [!CAUTION]
> 风险警示：某些操作可能带来的负面后果。

## 大小写不敏感

> [!note]
> 小写标记同样渲染（`[!Note]`、`[!nOtE]` 亦可）。

## 富内容

> [!TIP]
> 第一段：支持 **加粗**、`行内代码` 与 [链接](https://github.com)。
>
> 第二段：空行分隔的多段落。
>
> - 列表条目一
> - 列表条目二

## 空提示框

> [!IMPORTANT]

## 嵌套引用中的 Alert

> 外层引用
>
> > [!WARNING]
> > 嵌套引用里的警告框。

## 不识别的形态（优雅降级为普通引用，原文保留）

以下写法**不会**渲染为提示框，与 GitHub 行为一致（VividMark 有意从严）：

> [!HINT]
> 未知类型（GitHub 只认五类；hint 请用 `::: hint` 或 `!!! hint`）。

> [!NOTE] 行内标题
> 标记后同行跟文本不识别（GitHub 不支持行内标题）。

> [!note]-
> Obsidian 折叠标记 `-` / `+` 暂不支持，原样保留。

> 前文文字
> [!CAUTION]
> 标记不在引用块首行不识别。

## WYSIWYG 编辑说明

- 标记行在所见即所得中**可见可编辑**：把 `[!NOTE]` 改成 `[!TIP]` 立即换主题色，
  删掉 `]` 退回普通引用块。
- 保存后源码中的 `[` 可能被序列化为 `\[`（防链接误判的转义，语义相同），
  双端都能继续识别为 Alert。
